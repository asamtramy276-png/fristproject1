# نظام إدارة مدارس الكمال ترند لينك الصناعية (K Link)

## محتويات الملف المضغوط
- `index.html`: الواجهة الرئيسية ونظام الدخول الآمن.
- `styles.css`: تنسيقات الواجهة العربية (RTL) والبطاقات والجداول.
- `app.js`: منطق التحقق من الهوية، بوابات الطالب/ولي الأمر والمدرب/المهندس، ولوحة تحكم الإدارة وحفظ البيانات محلياً (`localStorage`).
- `assets/school-logo.svg`: شعار المدرسة المرفق بالنظام.

## طريقة التشغيل
1. فك الضغط عن الملف في مجلد على جهازك.
2. افتح `index.html` مباشرة في المتصفح أو عبر **Live Server** في Visual Studio Code.
3. سجل الدخول حسب الصلاحية (طالب / ولي أمر، مدرب / مهندس، أو إدارة) دون ظهور أي أرقام قومية أو تلميحات في شاشة الدخول.
